# SWYNEX Python CLI Task Manager

A command-line task management application built with Python as part of the SWYNEX Python Internship.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks by keyword
- Case-insensitive task search
- Unique task IDs
- Input validation
- Exception handling
- Persistent JSON storage
- Modular Python code structure

## Technologies Used

- Python
- JSON
- Python Standard Library
- Git & GitHub
